# Работа над домашним заданием в Python

## Описание:
Проект создан для проверки полученных знаний на практике. Этот проект для банковского приложения, который на бэкенде будет готовить данные для отображения в новом виджете.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
